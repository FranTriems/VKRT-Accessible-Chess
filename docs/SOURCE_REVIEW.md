# Public source review and historical evidence

R31 candidate ZIP is SHA-256 bound in release preparation. Public export includes native C++ sources/tests and Android Java/JNI/Gradle sources/tests plus release documentation. It excludes the original private React Native archive, sessions, local logs, run workspaces, caches, signing keys, compiled binaries and user data.

The `docs/` and README files describe current R31 state. Older candidate notes such as R29_ACCEPTANCE/AGENTS/TASK_CODEX/TEST_REPORT, which contain pre-APK statements or older constraints, were intentionally not copied into the public repo. Original R31 ZIP remains a private review artifact.
